# Data provenance and licensing

The MIT license applies to this project's software and project-authored documentation. It does not relicense third-party datasets.

MultiPref source: https://huggingface.co/datasets/allenai/multipref, default configuration, upstream train split. The data page labels the dataset ODC-BY: https://opendatacommons.org/licenses/by/1-0/ . Cite Miranda et al., *Hybrid Preferences: Learning to Route Instances for Human vs. AI Feedback*, ACL 2025 / arXiv:2410.19133; the dataset-supplied citation is in CITATION.bib.

The pilot uses the first 2,000 comparisons, not a random sample of the full dataset. Original five-level labels remain in local preprocessing; only A/Tie/B are used in these estimators. Raw and processed real annotations, prompt/response text and evaluator-level label records are excluded from Git and the final distribution. Dataset-derived aggregate results, reference distributions and comparison/prompt identifiers in experiments/phase1 and experiments/phase2 retain MultiPref attribution and any applicable ODC-BY obligations; they are not represented as a newly MIT-licensed database. Synthetic label arrays are generated by this project.

The download is bounded but not pinned to an upstream revision. An exact historic replication requires the matching local raw bytes and SHA256 in experiments/phase1/data_audit.json. A later download with a different hash is a new input, not an exact replication. Do not silently substitute a later dataset for the preserved pilot. No corporate or private feedback data are used.
