# 假设及其适用范围

| 假设 | S1 | S2 | MultiPref |
|---|---|---|---|
| 四槽位给定组别条件独立 | 由生成器保证 | 被未观测共享潜在因素打破 | 不保证；同问题、回答与重复标注者可能造成依赖 |
| 每组有固定三分类概率 | 成立 | 只在边缘上成立，潜变量内概率不同 | 工作模型，忽略类别与问题异质性 |
| 筛选核已知 | 模拟保证 | 模拟保证 | 本轮人为删失模拟保证；不代表真实生产筛选 |
| 完整审计独立于标签 | 固定数简单随机抽样保证 | 同左 | 同左；实际审计若有非响应则不保证 |
| 两组各两份与等权目标 | 成立 | 成立 | 仅完整有效比较进入分析 |
| 标签具有全球偏好效度 | 不涉及 | 不涉及 | 未建立 |

S1 组概率 normal=(.60,.25,.15)、expert=(.40,.15,.45)。S2 Z∈{−1,+1} 各 1/2，normal 概率 p+Z(.30,−.15,−.15)，expert 概率 p+Z(.30,−.10,−.20)。给定 Z 后独立，但估计器看不到 Z，边缘概率仍为 p。用共享潜变量产生同一比较内相关，不人为泄漏潜变量。

完整数据仅由模拟器、审计释放接口和最终评分代码读取；Observed 是独立只读副本，以 −1 隐藏标签，没有 Oracle 引用。估计器 API 只接受 Observed 和 Audit，不接受完整样本表或筛选日志。这是工程访问边界，不是恶意代码无法绕过的安全沙箱。

真实数据只是 API 顺序前 2000 比较，不是从全库简单随机抽样；不能推广整个 MultiPref。prompt 分组划分防止同问题跨分区，但重复 evaluator 仍跨比较，未建模。五次种子只量化给定完整目标上的筛选/审计随机性；不是独立抽取五份人群数据，不提供总体显著性。四槽位不是四个独立有效比较样本。
