# ConsensusCensor 最终项目总结

**Engineering Artifact: READY**

**Original Research Contribution: NOT ESTABLISHED**

## 研究背景与边界

研究共识筛选如何改变人类偏好标签的观察分布，以及少量随机完整审计能够恢复多少信息。目标是公开数据内四个标注槽位的经验分布，不是全球偏好或下游模型质量。项目已正式收口，不进入 Phase 3。

## 两阶段完成内容

Phase 1 实现 M0–M2、B0–B3、81 状态似然、数据转换和 2000 比较 Pilot。Phase 2 实现既有 HT 残差估计、M2 后分层、两种交叉拟合辅助估计；各场景 50 次固定总体审计、20 个独立总体，真实分区各 30 次审计，保存 28800 个方法运行。最终收口只新增小规模复现和检查，没有重新运行大型实验或修改冻结协议。

| S1 | 0.14027 | 0.01792 | 0.01792 | 0.00394 | 0.01507 | 0.00972 | 0.00967 | 0.00966 |
| S2 | 0.13055 | 0.02369 | 0.02369 | 0.04001 | 0.01867 | 0.00831 | 0.00836 | 0.00995 |
| S3 | 0.14190 | 0.02358 | 0.02358 | 0.02832 | 0.01652 | 0.00868 | 0.00868 | 0.00876 |

表格对应 M2、20% 审计的固定合成总体半 L1 平均损失。模型正确时 B3 更精确；共享因素和难度异质性会使其产生稳定偏差。B4 通过估计缺失残差降低模型依赖，但不保证误差或方差总是优于仅审计。M2 简单后分层已是强基线，复杂 B3 辅助没有形成稳定优势。真实 Pilot 上 B3 的总体误差仍较低，设计稳健性没有自动变成所有指标的优势。

## 统计正确性与最终核查

设计期望独立穷举最大差异 1.11e-16。B4 证明基于已知正入样概率；B5 采用固定 prompt 折、折外训练和实际折审计数形成的条件入样概率。组内分母为 2，总体为两组等权平均；M2 使用真实删除层权重。所有方法共享同一观察视图及审计索引，允许信息的不同使用方式属于基线定义。

3 次 B3 数值失败有有限原始值；12 次 B5b 失败没有输出。历史主要均值只针对成功运行，不能理解为无条件算法风险。最终新增失败损失敏感性范围、共同成功运行配对和失败率。真实 M2/20% 的 B5b 均值来自 29/30 次成功运行。原始结果没有被替换。

B4 总体或组内概率和可能不为 1，统一以半 L1 损失描述原始向量；只有合法概率向量才称标准 TV。不裁剪、不投影。固定总体审计变化与重新生成总体变化分别统计，不把审计 SD 当人群置信区间。

## 研究局限与停止原因

真实数据只是顺序前缀，筛选和审计均为受控模拟；未知机制、非随机审计、全局识别、置信区间覆盖率与下游效果均未建立。成功子集还可能受数值收敛选择影响。本项目没有新的 PPI/AIPW/GREG/HT 理论或原创算法。

研究负责人决定停止新增算法研究：现有方法已解决相当一部分目标问题，本轮证据不足以支持六个月的原创算法研究投入。代码量、测试数量和实验次数不改变这个判断。不会再建议或自动进行 Phase 3。

## 最小复现命令

```bash
python -m pip install -e ".[dev,data]"
python scripts/reproduce_minimal.py
```

默认输出 experiments/minimal；已有输出时请用 --output 指定新的空目录。无需下载真实数据或运行全部大型实验。详见 reproducibility_guide.md。
