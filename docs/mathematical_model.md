# 模型、似然与限制

## 参数与生成模型

p_g=(p_gA,p_gT,p_gB)，每组两个自由参数；初期不使用 category 分层。四槽位在给定组别后独立：f_p(y)=∏_{j=1}^4 p_{g_j,y_j}。这是强工作假设，而非对真实数据的事实断言。总体输出为两组 p 的等权平均。

设 o 为可见标签和其槽位，K_m(o|y) 为已知筛选核。M0 对四个删除槽位各赋 1/4；M1 计算四个三元子集代价，只对并列最小子集均匀分配；M2 不满足至少三同类时映射为全隐藏，否则保留完整 y。保留槽位本身是观测事件的一部分。tie 指示可依赖隐藏标签，只保存于筛选日志，不传入估计器。

未审计样本贡献 q_p(o)=Σ_{y∈{A,T,B}^4} K_m(o|y)f_p(y)。M2 的全隐藏事件贡献 Σ_y 1(max_c count_c(y)<3)f_p(y)，每个被剔除比较都计入，绝不条件化为仅保留样本。

完整审计样本贡献 f_p(y)。总对数似然为 Σ_i[A_i log f_p(y_i)+(1−A_i)log q_p(o_i)]。审计样本不再计入未审计项。若附加保留其筛选事件，K(o|y) 是已知且与参数无关的常数；当前省略。均匀固定数抽样在给定样本量后独立于标签，审计抽样因子同样可省略。

精确枚举 81 状态，预先构造事件×状态矩阵 K，按实际事件频次压缩。用四维 logits 的 softmax 表示 p，B 为参照类；对数联合质量与解析梯度用 SciPy L-BFGS-B 优化。固定三起点、500 次迭代、logits∈[−20,20] 仅用于数值稳定，记录触边，不将其当成识别证据。目标概率非正时返回无穷损失；不把不可能事件加 epsilon 伪造为有效事件。正概率极小及边界仍可能产生病态。

## 可识别性与数值诊断

正审计比例在随机代表性审计、足够样本和正确记录下，原则上提供组别边缘分布的信息，Audit-Only 本身无需四标注条件独立。有限审计仍可能极不稳定。零审计不代表无信息：观测标签、槽位和 M2 剔除计数仍有信息；但信息来自筛选核和参数模型，不能推广至无模型恢复。

每次 B3 报告全部可观测事件概率映射的四参数 Jacobian 局部秩、最小奇异值、近等似然多起点参数差、优化状态与触边。局部满秩不是全局一一映射的证明，也不是有限样本信息量足够的证明。本轮未给出全局识别证明、置信区间或统一收敛保证。稀疏、边界、非收敛结果全部保留；不增加不合理约束掩盖失败。

B0 对真正保留槽位池化，总体不强制按组等权，另报告组别分布。B1 仅完整审计标签池化；B2 组别分层再以 1/2 合成。当前每次完整审计两组各两份，所以 B1=B2 是设计的代数结果，不是实证新发现。零审计 B1/B2 不可用，输出 NaN 而非均匀先验。不存在筛选时 B3 回到两组分类经验频率。
