# 第一阶段冻结协议

1. Python 3.11+ CPU；无付费 API、无 GPU、无网络服务、无大型模型。运行 `python scripts/prepare_data.py` 下载 default/train 的前 2000 行，每请求最多 100 行，拒绝截断单元格；数据许可 ODC-BY。记录实际 Schema、数据哈希、五档原始计数和异常。比较 ID 去重、prompt ID 非空、两组各两份且标签可映射，才进入完整比较分析。匿名 evaluator 仅保存预处理表，不进入模型。
2. 原始标签 A-is-clearly-better/A-is-slightly-better→A，Tie→T，B 两档→B；未知值记录并排除对应比较，不归 Tie。样本和标注分为两张 Parquet 表，保留 preference_raw。
3. M0 随机删一槽；M1 按 A=0/T=1/B=2 的三槽两两绝对距离和最小化，均匀随机解平局；M2 至少三同类才保留全部。机制分开运行，记录槽位、平局、版本、种子；S2 潜变量不传给估计器。
4. 至少 20 项测试通过后才运行完整合成实验；S1/S2 每个固定目标 1500 个比较，生成种子 20261022。每个目标上筛选/审计种子为 11、23、37、41、59。合成实验完成后才运行真实 Pilot。
5. 对唯一 prompt_id 按种子 20261022 打乱，60%/20%/20% 分训练、验证、测试；实际比较数可略偏离该比例。保存逐比较分区清单。无超参数选择，组别独立模型、三起点优化与其他设置预先冻结并保存 SHA256；训练、验证、测试按序执行。
6. 每个目标分区单独估计该分区有限槽位分布。测试不是训练后预测新标签：它是对锁定测试集合做受控删失后的分布恢复；只拟合允许读取的测试观测和规定审计数据，隐藏测试 Oracle 仅用于最终评分。训练/验证拟合不传入测试；本轮没有 X→Y 预测器。
7. 每个种子先随机打乱比较索引，审计量 floor(n×比例)，比例 0/5/10/20%；审计顺序跨机制和方法相同，预算嵌套。完整审计样本由单独接口释放。不重复计入 B3 似然。B0 固定使用原筛选标注，B1/B2 仅审计，B3 使用两者。零审计 B1/B2 记不可用，不计为优化失败。
8. 每次输出总体 TV、支持度绝对误差、normal/expert TV、两组支持度差误差、组间 TV 差误差、完整概率、时间、优化失败/触边/局部秩。合成额外对生成参数评分；真实仅对有限完整标注参考评分。记录每种机制的样本/标注保留率及各类删除率。
9. 用五次成对随机化的均值与标准差描述，保存所有重复。无显著性声明；未执行 Bootstrap，不将槽位作为独立统计重复。主比较为锁定测试分区；训练/验证仅补充描述。所有数值结果由脚本生成。
10. 范围上限 2000 真实比较；不因负面结果更改模型、目标、数据量、种子或起点。本轮停止于报告决策证据，不决定后续课题。
