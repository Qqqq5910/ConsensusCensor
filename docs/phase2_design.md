# Phase 2 固定研究设计

## 继承与保护

本轮沿用现有 ConsensusCensor，不涉及 FunnelBounds，不新建仓库或远端。首先核实本地仓库、Phase 1 压缩包、原始 2000 比较与原分区均存在；恢复 Python 依赖后，原 29 项测试重新通过。原文件哈希记录于 experiments/phase2/phase1_preservation.json，结束时再次比较。Phase 1 代码、文档、结果、原始数据均不覆盖。本轮不重跑 run_phase1.py，以免它覆盖原结果。

## 锁定估计器

- B0/B1/B2/B3 使用原代码重新计算，不把历史数字作为本轮结果。
- B4 为可见贡献加缺失残差的 Horvitz–Thompson 校正。全局固定数量 k、不放回 SRS，真实 pi=k/N，k=floor(rate*N)。组内分母为 2，总体为两组等权平均。
- B4-M2 为已知保留/删除层权重下的常规后分层估计，只有删除层需要审计均值，空删除审计层不可估计。非 M2 标记不适用。
- B5a 在训练折的完整审计数据中，按普通/专家组统计原本缺失的标签频率，三类各加 .5 伪计数；若组内没有缺失训练标签则使用对称平滑先验。按目标组缺失槽位数缩放，只预测缺失贡献。
- B5b 在其他折的可见数据和完整审计上训练原 B3，使用 81 状态与实际事件选择核计算缺失贡献后验均值，包含 M1 的保留子集和并列选择概率、M2 的删除事件。不直接用 B3 总体估计替换标签。
- B5 系数固定为 1，无自适应权重或测试真值调参；不进行概率投影。原始负值、越界及质量和异常全部保留。

## 审计设计与折

每个目标集合按 metadata 中 prompt_id 分为两个不重叠折，种子 20261022，只基于问题标识，不读取标签或审计结果来分折。所有方法共享完全相同的全局 SRS 审计索引、原始观测视图与审计预算。比例 0/5/10/20%，不同预算使用同种子随机排列前缀。各方法 audit_hash 必须相同。

B4 使用边缘 pi=k/N。固定总审计量意味着各折审计计数相关，单纯按 prompt 交叉拟合不自动给出有限样本设计无偏。B5 使用给定实际各折审计数后的条件 pi_f=k_f/N_f；在固定折计数下，折内选择与其他折选择独立，折外训练可应用条件广义差分期望论证。未知折 k_f=0 时不可估计，不重新抽样直到成功、不丢弃失败种子。估计器训练完全排除目标折，包括其可见记录；预测时只读取目标可见记录。完整目标折审计标签仅用于残差校正。

## 三种合成场景

S1/S2 直接调用未修改的第一阶段生成器；S1 组别独立，S2 共享未观测潜在因素引起相关。S3 为指定难度混合：高一致性层概率 .55，normal=(.90,.07,.03)、expert=(.85,.05,.10)；高分歧层概率 .45，normal=(.20,.35,.45)、expert=(.35,.40,.25)。给定层和组别后独立，潜在层不进入筛选或预测接口；其边缘概率由配置明确计算。三场景大小均 800，CPU 可运行。

实验一：每场景固定一个完整总体（生成种子 20261022）和一次 M0/M1/M2 观测视图（筛选种子 314159）；每场景使用 11001–11050 共 50 个审计种子。变化来自审计，而非重新生成标注或重新筛选。

实验二：每场景分别使用 21001–21020 共 20 个独立生成种子；固定审计种子 7007 和筛选随机流 314159。相同索引样式有助于隔离人口生成变化，不能把 20 个总体与实验一的 50 次审计拼为独立重复。评价主目标仍是每个生成总体的有限槽位分布，另保存相对已知生成参数的误差。

## 真实数据

严格验证原始 JSON SHA256 与第一阶段 data_audit.json 相同，保留已有 1201/399/400 比较的 train/validation/test prompt 分组。不会重新下载或改变数据顺序。每个分区使用 31001–31030 共 30 个审计种子，同一固定筛选视图。顺序为合成、真实训练、真实验证、真实测试；方法、超参数、两折及权重已在读取测试评分真值前冻结。测试仍是允许观测与审计条件下的有限分布恢复，而非训练后预测新样本标签。完整测试标签只由筛选模拟器、规定审计释放与最终评分读取，不进入未审计预测训练。

## 指标与统计单位

保存每次原始总体/两组 A/T/B、每类有符号误差、支持度差有符号/绝对/平方误差、总体/两组 TV、MSE、数值失败、不可估计及非法原始向量比例。MSE 是三个类别坐标误差平方的平均。对非法原始向量，半 L1 损失仍记录，但不能严格称为概率分布 TV。

固定总体内报告审计随机化偏差/SD/方差，跨总体结果单独报告。各指标主均值仅汇总 status=ok；非收敛的有限数值原样保留在 results.csv，不静默替换，配对比较列出共同成功次数。无显著性或人群置信区间声明。CPU 时间使用 process_time，包含 B5 的折训练；不含下载/筛选/I/O。

extra_labels 只计审计样本原本隐藏的槽位，audit_full_slots=4k 是完整审计名义槽位。B0 不使用审计，但表中成本列表示该固定协议给各方法共同分配的预算；不能将它解释为 B0 实际需要的标签量。M2 已可见标签不计新增获取成本。

优先审计删除层的不同设计属于允许但非必须补充，本轮未运行；因此不把设计变化的收益归功于估计器。本轮无前端、无付费 API、无模型训练，不自动延长研究。
