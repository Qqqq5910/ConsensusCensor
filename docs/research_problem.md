# ConsensusCensor 第一阶段研究问题

这是研究原型，不是生产系统；不声称方法原创。目标是 RQ1 给定共识筛选引起的分布变化、RQ2 少量随机完整审计辅助下的恢复能力、RQ3 可识别性及模型错误的失败方式。不研究下游奖励模型或 LLM 质量。

每个比较 i 有四个槽位 j，固定顺序 normal0、normal1、expert0、expert1。X 包含公开比较元数据，Y∈{A,T,B}，G 为组别，M 为槽位可见状态，S 为样本保留状态，A_i 为随机审计指示。完整审计释放四个槽位，不只释放被删除标签。

有限数据目标 θ_gc = (2n)^(-1)Σ_iΣ_{j:G_j=g}1(Y_ij=c)，θ_c=(θ_normal,c+θ_expert,c)/2。θ_score=θ_A+0.5θ_T。群体支持度差定义为专家支持度减普通支持度；同时报告两组分布的 TV 距离差误差。A/B 是候选回答方向，不是好坏真值。

MultiPref 四标注分布只称为完整标注参考，不代表全球偏好、所有用户或唯一正确质量。合成实验另以生成参数为统计真值，并同时评估实际有限样本参考分布。五档强度原样保存在 annotations.parquet 的 preference_raw，三分类暂不使用强度。

本地目录中 data/ 被 Git 忽略。完整原始真实数据不进入提交或交付压缩包；可按有界脚本重新下载。
